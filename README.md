#  Шашки с Q-learning AI

Простая игра в шашки, где сначала два AI учатся играть друг против друга, а потом ты играешь против них.

---

##  Файлы проекта

* `checkers_engine.py` — логика игры (ходы, правила)
* `train.py` — обучение AI
* `merge.py` — объединение двух AI
* `play.py` — игра против AI (через pygame)
* `requirements.txt` — зависимости
* `model/` — сюда сохраняются модели

---

##  Как это работает

AI обучается с помощью Q-learning — он запоминает, какие ходы хорошие, а какие плохие.

Сначала:

* 2 AI играют между собой (~60 000 игр)
* каждый учится отдельно

Потом:

* их знания объединяются в одну модель

---

## Как запустить

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Обучить AI:

```bash
python train.py
```

3. Объединить модели:

```bash
python merge.py
```

4. Играть:

```bash
python play.py
```
